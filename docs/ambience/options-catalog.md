# Ambience Options Catalog

- Stack family: node
- Setup effort: low
- Rationale: existing lockfile and workflow compatibility

## Option B: pnpm
- Stack family: node
- Setup effort: medium
- Rationale: good performance but requires migration work

## Option C: yarn
- Stack family: node
- Setup effort: medium
- Rationale: viable alternative but no clear net gain here

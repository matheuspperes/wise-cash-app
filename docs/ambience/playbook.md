# Ambience Playbook

## Standard Workflow
1. Confirm project context.
2. Score options with rubric.
3. Publish recommendation report.
4. Validate against contract and manual checklist.
5. Sync quickstart and operational baseline.
6. Record evidence and schedule re-evaluation reminder.

## Baseline Policy
- Non-Python current repository: npm
- Python contexts: uv

## Governance
- Re-evaluate on major stack change or 6-month cycle.
- Keep traceability in reevaluation-log.md.

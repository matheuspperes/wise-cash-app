# Reevaluation Policy

## Triggers
Reevaluate ambience when at least one condition is met:
1. Runtime of primary stack changes.
2. Official dependency manager for primary stack changes.
3. Documented setup command set changes by 30% or more.
4. Six months have elapsed since the last formal review.

## Process
1. Open a re-evaluation entry in reevaluation-log.md.
2. Re-score options with rubric.md.
3. Update recommendation-report.md with decision and impact.
4. Mark previous recommendation as superseded if applicable.
5. Record next reminder date (+6 months).

## Reminder Process
- Owner reviews monthly backlog and checks upcoming 6-month due dates.
- If due date falls within 14 days, create a reminder task in team backlog.

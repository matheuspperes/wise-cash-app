# Ambience Option Scoring Rubric

## Dimensions (1-5)
1. Setup friction
2. Repeatability
3. Ecosystem alignment
4. Migration effort
5. Operational clarity

## Weighting
- Setup friction: 30%
- Repeatability: 25%
- Ecosystem alignment: 20%
- Migration effort: 15%
- Operational clarity: 10%

## Rule
- Highest weighted score wins unless a hard constraint is violated.
- In tie situations, prefer the option with lower migration effort.

# Manual Validation - Recurrences View

## Objective
Validate the `?view=recurrences` screen with `Pendências` and `Recorrências` blocks.

## Checklist
- [ ] `Pendências` block is visible
- [ ] Empty state shows `Sem confirmações pendentes` when no pending items
- [ ] `Recorrências` block is visible
- [ ] Recurrence item shows name, value, next date, type, status and actions
- [ ] Status labels are correct (`Ilimitada`, `1 mês faltante`, `N meses faltantes`, `Sem ciclos restantes`)
- [ ] `Editar` action opens editor while list remains visible in background
- [ ] `Excluir` action requires explicit confirmation
- [ ] Confirm/cancel pending actions refresh the screen data

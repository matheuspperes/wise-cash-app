# US3 Checklist - Cross-Screen Consistency

## Scenarios
- [ ] Date formatting is consistent between dashboard and transactions
- [ ] Currency/value formatting is consistent between dashboard and transactions
- [ ] Table labels and column semantics are consistent
- [ ] Dashboard to transactions navigation preserves expected context framing
- [ ] No visual regression on dashboard cards and chart block

# US1 Checklist Manual

## Objetivo
Validar cadastro, edicao, exclusao logica e recorrencia mensal.

## Cenarios
- [ ] Criar transacao de ganho com todos os campos obrigatorios
- [ ] Criar transacao de gasto com todos os campos obrigatorios
- [ ] Bloquear envio sem nome, valor, data ou categoria
- [ ] Editar transacao existente
- [ ] Excluir transacao e validar exclusao logica
- [ ] Criar transacao recorrente e validar proxima ocorrencia
- [ ] Validar fallback para ultimo dia do mes

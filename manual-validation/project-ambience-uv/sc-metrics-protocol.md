# Success Criteria Measurement Protocol

## SC-001
Verify recommendation report contains 1 primary option and >=2 alternatives.

## SC-002
Record decision rounds and confirm first-round closure ratio.

## SC-003
Run onboarding dry-run and confirm completion without facilitator support.

## SC-004
Measure setup time baseline vs new baseline and compute percentage delta.
Formula: ((baseline_time - new_time) / baseline_time) * 100.

## SC-005
For each re-evaluation event, verify decision criteria, expected impact, and continuity plan are logged.

# Validacao Manual - Pendencias Manuais

## Objetivo

## Cenarios
- [ ] Criar 1 pendencia por ciclo para regra unlimited manual

- [ ] Cancelar pendencia e validar nao recriacao no mesmo ciclo

- [ ] Validar preservacao de pendencias ao desativar regra
- [ ] Validar independencia da regra apos editar/remover transacao base
